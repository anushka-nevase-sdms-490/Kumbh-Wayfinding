# Setu Frontend (React)

Pilgrim web app: scan/select start → pick destination → follow arrow on man-made routes.

## Folder

```
frontend/
  src/           # React UI
  public/        # Static files
  package.json
```

## Run

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173

## Flow

1. **Find my way**
2. **Scan QR** or select **starting point**
3. Select **destination**
4. See **direction + route** (not satellite roads)

Optional: start backend first so the live pack loads from the API.
